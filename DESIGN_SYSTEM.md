# The Verdigris Interface Protocol™

**Aesthetic Philosophy**: "Ancient Roman Glass" meets "Cyberpunk Brutalism".
**Core Tenet**: The Silence of True Automation.

## 1. Color Palette: The Triadic Splendor

| Role | Color Name | Hex | Usage |
|------|------------|-----|-------|
| **Primary** | Imperial Purple | `#6A0DAD` | Brand identity, leadership, magic/AI core. |
| **Secondary** | Patina Green | `#3EB991` | Success, safety, financial growth, organic life. |
| **Accent** | Roman Aqua | `#20B2AA` | Interactive elements, data flow, active states. |
| **Warning** | Gilded Accent | `#FFD700` | Notifications, wealth, attention. |
| **Background** | Obsidian Black | `#000000` | Deep space background, high contrast. |

## 2. Typography

*   **Headers**: `Comfortaa` (Rounded, Geometric) - Evokes a friendly yet futuristic softness.
*   **Body/UI**: `Lexend` (Sans-serif) - Designed for maximum legibility and reduced eye strain.
*   **Data/Code**: `Martian Mono` - Technical precision, used for logs and metrics.

## 3. Glassmorphism Parameters

The "Glass" effect is not just transparency; it represents physical depth and age.

*   **Background**: `rgba(20, 20, 20, 0.6)` (Dark, smoky glass)
*   **Blur**: `backdrop-filter: blur(20px)` (Heavy frosting)
*   **Border**: `1px solid rgba(255, 255, 255, 0.1)` (Subtle etching)
*   **Shadow**: `0 8px 32px 0 rgba(0, 0, 0, 0.5)` (Deep ambient occlusion)

## 4. Motion Principles

*   **"Digital Wabi-Sabi"**: Animations should feel organic, not perfectly linear. Use `spring` physics over `ease-in-out`.
*   **Entrance**: Elements should drift in (`y: 10` -> `0`, `opacity: 0` -> `1`).
*   **Feedback**: Interactive elements must "glow" or "pulse" upon interaction, simulating energy transfer.

## 5. Iconography ("Aetheric Sigils")

Icons are treated as carved glyphs.
*   They often feature a subtle internal glow (`drop-shadow`).
*   Active states are indicated by color shifts (Grey -> Triadic Color) and pulsing animations.

## 6. Layout Metaphors

*   **The Cockpit (C-HUD)**: Fixed, immersive overlay. The user is a pilot.
*   **The Canvas (Weaver)**: Infinite, pannable space. Represents the "Void" of creation.
*   **The Obelisk**: A central anchor point in dashboards, representing accumulated value.
*   **High-Density Layout**: Spacing-optimized design paradigm for maximum information density in dashboards and views, ensuring compliance with 44px touch target minimums.
